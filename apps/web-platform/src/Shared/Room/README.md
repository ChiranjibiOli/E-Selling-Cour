# Frontend room standard

Every room must contain:

- `Route.php`
- `Controller.php`
- `Middleware.php`
- `Request.php`
- `Validator.php`
- `Service.php`
- `ApiClient.php`
- `ViewModel.php`
- `Page.php`
- `Components/README.md`
- `Assets/page.css`
- `Assets/page.js`
- `Tests/README.md`
- `ROOM.md`

The room derives its route, role, backend service, and implementation status from `src/config/rooms.php`.
